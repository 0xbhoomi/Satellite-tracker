# Satellite Tracker
Satellite Tracker is a beginner-friendly web application that shows the real-time location of the International Space Station (ISS) on an interactive world map.
It uses live satellite data to display latitude, longitude, altitude, and speed, helping students visualize how satellites orbit the Earth.
## Features
- Real-time ISS position
- Interactive world map
- Auto updates every 5 seconds
- Educational explanation section
## Tech Stack
- HTML
- CSS
- JavaScript
- Leaflet.js
- whereTheISS API
## How to Run
1. Download or clone the repository.
2. Open index.html in any web browser.
